## 🤖 Securing AI

<div class="resource-section ai-section" id="ai-security-section">

<div class="resource-subsection ai-red">
<h3>🔴 AI Red Teaming</h3>
<p class="subsection-desc">Open source tools and frameworks for adversarial testing, attacking, and evaluating AI/ML systems.</p>
<ul class="resource-list">
<li><a href="https://github.com/Azure/PyRIT" target="_blank">PyRIT</a> — Microsoft's Python Risk Identification Toolkit for generative AI. Automates red teaming of LLMs, multimodal models, and AI pipelines.</li>
<li><a href="https://github.com/NVIDIA/garak" target="_blank">Garak</a> — LLM vulnerability scanner. Tests for prompt injection, jailbreaks, data leakage, hallucination, and more across many model providers.</li>
<li><a href="https://github.com/promptsecurity/ps-fuzz" target="_blank">ps-fuzz (Prompt Fuzzer)</a> — Open source tool for fuzzing LLM system prompts to find injection vulnerabilities and weaknesses.</li>
<li><a href="https://github.com/promptfoo/promptfoo" target="_blank">promptfoo</a> — Test and red-team LLM prompts and apps with repeatable, version-controlled eval configs.</li>
<li><a href="https://github.com/protectai/ai-exploits" target="_blank">AI Exploits (ProtectAI)</a> — Real-world exploits and vulnerabilities found in ML infrastructure and AI tooling. Maintained by the ProtectAI team.</li>
<li><a href="https://github.com/Trusted-AI/adversarial-robustness-toolbox" target="_blank">Adversarial Robustness Toolbox (ART)</a> — IBM's library for defending ML models against adversarial attacks: evasion, poisoning, extraction, and inference attacks.</li>
<li><a href="https://github.com/cleverhans-lab/cleverhans" target="_blank">CleverHans</a> — A Python library to benchmark ML model vulnerability to adversarial examples.</li>
<li><a href="https://github.com/QData/TextAttack" target="_blank">TextAttack</a> — A framework for adversarial attacks, data augmentation, and adversarial training in NLP.</li>
<li><a href="https://github.com/microsoft/promptbench" target="_blank">PromptBench</a> — Microsoft's unified library for evaluating and benchmarking LLM robustness against adversarial prompts.</li>
<li><a href="https://github.com/Azure/counterfit" target="_blank">Counterfit</a> — Microsoft's automation layer for assessing the security of ML systems across multiple attack types.</li>
<li><a href="https://github.com/cyberark/FuzzyAI" target="_blank">FuzzyAI</a> — CyberArk's automated LLM fuzzer for surfacing jailbreaks and injection weaknesses in model APIs.</li>
<li><a href="https://github.com/utkusen/promptmap" target="_blank">promptmap</a> — A prompt-injection scanner aimed at custom LLM applications.</li>
<li><a href="https://github.com/confident-ai/deepteam" target="_blank">DeepTeam</a> — An LLM red-teaming framework with 40+ vulnerability types and 10+ attack methods, mapped to the OWASP LLM Top 10.</li>
<li><a href="https://github.com/sherdencooper/GPTFuzz" target="_blank">GPTFuzz</a> — Automated jailbreak-template generation for stress-testing LLM guardrails.</li>
<li><a href="https://github.com/agencyenterprise/PromptInject" target="_blank">PromptInject</a> — A framework for assembling and quantifying adversarial prompt-injection attacks.</li>
<li><a href="https://github.com/mik0w/pallms" target="_blank">PALLMs</a> — A collected set of payloads for attacking LLMs, handy for building test suites.</li>
<li><a href="https://github.com/bethgelab/foolbox" target="_blank">Foolbox</a> — A toolbox for crafting and evaluating adversarial examples against models in PyTorch, TensorFlow, and JAX.</li>
</ul>
</div>

<div class="resource-subsection ai-blue">
<h3>🔵 AI Blue Teaming & Defense</h3>
<p class="subsection-desc">Open source tools for monitoring, protecting, and securing AI/ML systems and applications in production.</p>
<ul class="resource-list">
<li><a href="https://github.com/protectai/rebuff" target="_blank">Rebuff</a> — Self-hardening prompt injection detector. Uses LLM-based detection, a canary token system, and a shared database of attack signatures.</li>
<li><a href="https://github.com/protectai/llm-guard" target="_blank">LLM Guard</a> — A comprehensive security toolkit for LLM interactions: input/output scanning for prompt injection, PII, toxicity, and code detection.</li>
<li><a href="https://github.com/NVIDIA/NeMo-Guardrails" target="_blank">NeMo Guardrails</a> — NVIDIA's open source toolkit for adding programmable guardrails to LLM-based conversational applications.</li>
<li><a href="https://github.com/whylabs/langkit" target="_blank">LangKit</a> — An open source text metrics toolkit for monitoring LLM inputs/outputs. Detects prompt injection, toxicity, PII, and sentiment drift.</li>
<li><a href="https://github.com/deadbits/vigil-llm" target="_blank">Vigil</a> — LLM prompt injection and jailbreak detection server with REST API. Scans prompts against known attack signatures and semantic embeddings.</li>
<li><a href="https://github.com/mlflow/mlflow" target="_blank">MLflow</a> — Open source platform for ML lifecycle management including experiment tracking, model registry, and monitoring for drift.</li>
<li><a href="https://github.com/evidentlyai/evidently" target="_blank">Evidently AI</a> — Open source ML and LLM observability framework. Monitors model performance, data drift, and output quality over time.</li>
<li><a href="https://github.com/guardrails-ai/guardrails" target="_blank">Guardrails AI</a> — Open source framework for adding structural, type, and quality constraints to LLM outputs.</li>
<li><a href="https://github.com/meta-llama/PurpleLlama" target="_blank">Purple Llama</a> — Meta's suite of LLM safety tools, including Llama Guard, Prompt Guard, Code Shield, and CyberSecEval.</li>
<li><a href="https://github.com/meta-llama/PurpleLlama/tree/main/LlamaFirewall" target="_blank">LlamaFirewall</a> — A framework for detecting and mitigating security risks across multi-step agentic operations.</li>
<li><a href="https://nbdefense.ai/" target="_blank">NB Defense</a> — Scans Jupyter notebooks for secrets, PII, license issues, and vulnerabilities — a common blind spot in ML workflows.</li>
<li><a href="https://github.com/privacytrustlab/ml_privacy_meter" target="_blank">Privacy Meter</a> — Audits models for data-privacy risk by quantifying membership-inference exposure.</li>
<li><a href="https://github.com/JosephTLucas/lintML" target="_blank">lintML</a> — A security linter for ML codebases, from NVIDIA.</li>
<li><a href="https://github.com/tldrsec/prompt-injection-defenses" target="_blank">Prompt Injection Defenses</a> — A curated catalog of practical defenses against prompt injection, maintained by tl;dr sec.</li>
</ul>
</div>

<div class="resource-subsection">
<h3>🏛️ Governance, Standards & Frameworks</h3>
<p class="subsection-desc">Standards, control frameworks, and risk taxonomies for building and auditing an AI security program.</p>
<ul class="resource-list">
<li><a href="https://github.com/OWASP/AISVS" target="_blank">OWASP AI Security Verification Standard (AISVS)</a> — A structured set of verifiable security requirements for AI applications, in the spirit of ASVS.</li>
<li><a href="https://genai.owasp.org/resource/llm-applications-cybersecurity-and-governance-checklist-english/" target="_blank">OWASP LLM Cybersecurity & Governance Checklist</a> — A practical checklist for standing up governance around LLM adoption.</li>
<li><a href="https://owasp.org/www-project-ai-security-and-privacy-guide/" target="_blank">OWASP AI Security & Privacy Guide</a> — Guidance on securing AI systems and protecting privacy across the lifecycle.</li>
<li><a href="https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.100-2e2025.pdf" target="_blank">NIST Adversarial ML Taxonomy (AI 100-2)</a> — Standardized terminology and mitigations for attacks on ML systems.</li>
<li><a href="https://www.iso.org/standard/81230.html" target="_blank">ISO/IEC 42001</a> — The management-system standard for AI, useful when mapping AI governance to formal audit programs.</li>
<li><a href="https://saif.google/" target="_blank">Google Secure AI Framework (SAIF)</a> — Google's practitioner framework for securing AI systems end to end.</li>
<li><a href="https://cloudsecurityalliance.org/artifacts/ai-controls-matrix" target="_blank">CSA AI Controls Matrix</a> — A controls matrix for AI covering governance, risk, and compliance.</li>
<li><a href="https://incidentdatabase.ai/" target="_blank">AI Incident Database</a> — A searchable record of real-world AI harms and failures — useful for threat modeling.</li>
<li><a href="https://avidml.org/" target="_blank">AVID</a> — The AI Vulnerability Database: an open taxonomy and knowledge base of model failures.</li>
<li><a href="https://owaspai.org/" target="_blank">OWASP AI Exchange</a> — A large, collaboratively maintained knowledge base of AI threats and controls, mapped to standards and regulation.</li>
<li><a href="https://owasp.org/www-project-machine-learning-security-top-10/" target="_blank">OWASP ML Security Top 10</a> — The classic-ML counterpart to the LLM Top 10, covering attacks like data poisoning and model inversion.</li>
<li><a href="https://ethical.institute/security.html" target="_blank">The MLSecOps Top 10</a> — The Institute for Ethical AI's list of the top MLSecOps vulnerabilities.</li>
<li><a href="https://github.com/scadastrangelove/asamm" target="_blank">Agentic SAMM (ASAMM)</a> — An OWASP SAMM extension for AI-driven development: a threat taxonomy plus maturity-graded controls across five SAMM functions.</li>
</ul>
</div>
